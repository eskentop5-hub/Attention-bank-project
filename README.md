### Версия 10: финальная версия для защиты
- **Позиционирование B2B**: презентация на главной теперь о честных плейтестах для студий (проблема → решение → качество данных → отчёт → награды → unit-экономика → альтернативы → дорожная карта → пилот). Unit-экономика считается из настроек платформы и подписана как модель.
- **Качество данных против ботов и нейросетей** (`server/services/verification.js`): «детали продукта» — слова, которые знает только тот, кто играл (участник их не видит); флаги «текст вставлен», «набран быстрее человека», «шаблонный сгенерированный текст», «нет деталей продукта». Сайт отправляет только факт вставки и время набора, содержимое буфера не читается.
- **Ссылки-приглашения**: у каждой активной кампании есть ссылка `#/join/<код>` и вариант через бота `t.me/<бот>?start=join_<код>`. Гость регистрируется и сразу попадает в задание.
- **Отчёт для студии** `#/company/campaigns/:id/report`: воронка, цена результата в тенге, распределения оценок, частые слова, цитаты, сигналы проверки. Печатается в PDF, без имён и email участников.
- **Конфиденциальность**: страница `#/privacy` простыми словами, удаление аккаунта участника в настройках (личные данные обезличиваются, записи о баллах остаются для сверки).
- **Сервер не засыпает на Render**: при `PUBLIC_URL` на onrender.com сервер пингует себя каждые 10 минут (`KEEP_AWAKE=0` выключает).
- Маскот Аби с надписью «AB», гуляет по краю 3D-панели в презентации и не закрывает текст; красные звёзды заменены нейтральными элементами.

### Версия 9: Telegram v2 (`server/telegram/features.js`)
- **Mini App**: кнопка «Открыть» в меню бота и в сообщениях открывает сайт внутри Telegram. Вход без пароля по подписанным данным Telegram (`POST /api/telegram/webapp-login`, проверка HMAC токеном бота, срок 24 ч). При регистрации внутри Telegram аккаунт привязывается автоматически (`POST /api/telegram/webapp-link`), правило «1 Telegram = 1 аккаунт» сохраняется. Нужен HTTPS-адрес в `PUBLIC_URL`.
- **Задания прямо в чате** (`/tasks`): оценки и варианты — кнопками, текст и ссылки — сообщениями, проверка длины, «Пропустить» для необязательных, `/cancel`. Ответ уходит в ту же автопроверку, что и на сайте.
- **Компании проверяют ответы кнопками** «Одобрить / Отклонить» (с выбором причины) прямо в Telegram; баллы начисляются через леджер.
- **Напоминание о серии** раз в день в `REMINDER_HOUR` (по умолчанию 19:00) тем, кто ещё не заходил; `/remind on|off` и кнопка «Не напоминать».
- **`/stats`**: сегодня, вчера, позавчера, неделя с мини-графиком, серия, челлендж, процент одобрения.
- **«Хватает на цель!»** — уведомление в момент, когда баланс достиг стоимости выбранной цели.
- Новые команды бота: /app /tasks /stats /balance /history /remind /cancel /unlink.

### Версия 8: пароли, Аби с репликами, плавные анимации, кэш
- **Проверка пароля**: минимум 8 символов, буквы и цифры, запрет распространённых паролей и пароля из email или имени; поле «Повторите пароль», кнопка «показать», индикатор надёжности. Правила одинаковые на сервере и в интерфейсе.
- **Смена пароля** в Настройках с проверкой текущего (`POST /api/me/password`); остальные сессии завершаются.
- **Аби отвечает только готовыми репликами**: набор вопросов зависит от страницы, где открыт чат, после ответа предлагаются уточняющие вопросы. Чат закрывается при переходе на другую страницу.
- **Плавные анимации**: вход страниц, появление карточек при прокрутке «лесенкой», счётчики чисел, рост столбцов графика, окна, уведомления, кнопки (всё отключается при «уменьшении движения»).
- **Кэш**: HTML/JS/CSS всегда сверяются с сервером — после обновления не смешиваются старая и новая версии.
- Подвал со ссылками: О проекте, Экономика, игра, видео-тесты.
- Важно для Render Free: база SQLite живёт на временном диске и стирается при перезапуске/засыпании сервера. Чтобы сервер не засыпал, пингуйте `/api/health` каждые 5–10 минут (UptimeRobot / cron-job.org).

### Версия 6: экономика v2 — замкнутая и обеспеченная
- **AB создаются только пополнением бюджета** компанией (1 AB = `AB_TO_KZT` ₸). Бонус за Telegram теперь платится из доходов платформы, а не печатается; если у платформы нет средств — бонуса нет.
- **Баллы не сгорают при обмене**: продавец награды получает `100 − SELLER_FEE_PERCENT`% (по умолчанию 90%), платформа — комиссию с продажи.
- **Кабинет продавца «Выручка»** (`#/company/revenue`): чистая выручка в AB и ₸, продажи по наградам, график за 14 дней, доля бюджета тестов, вернувшаяся через продажу своих же наград, **заявки на вывод в тенге** (от `PAYOUT_MIN_AB`; в демо деньги не переводятся).
- **Публичная страница «Экономика»** (`#/economy`): AB в обороте и их обеспечение, схема потоков с живыми цифрами, автоматическая проверка казны (Σ балансов + резервы = пополнения − выводы), правила и калькулятор для компаний и продавцов.
- Участники выводить AB не могут — для них это баллы, только обмен на награды.
- Новый слайд «Экономика» в презентации, маскот знает новые правила. Тесты: 25.

## Быстрый запуск

Нужен **Node.js 22.13+** ([nodejs.org](https://nodejs.org)). Устанавливать пакеты не нужно, у проекта нет зависимостей.

```bash
npm start            # или на Windows: двойной клик по start-windows.bat
```

Откройте **http://localhost:3000**. Демо-доступ (пароль `demo1234`):

| Роль | Email |
|---|---|
| Участник | `demo@attention.bank` |
| Компания (студия) | `studio@attention.bank` |
| Компания (приложение) | `apps@attention.bank` |

```bash
npm test       # 19 сквозных тестов: деньги, безопасность, идемпотентность, Telegram
npm run dev    # запуск из исходников с автоперезагрузкой
npm run build  # пересобрать attention-bank-v2.mjs после правок (нужен esbuild: npm i -D esbuild)
npm run seed   # ⚠️ УДАЛЯЕТ локальную базу и создаёт демо-данные заново
```

`npm start` запускает один файл **`attention-bank-v2.mjs`**, в котором собраны сервер, сайт и бот. Для хостинга достаточно `package.json` и `attention-bank-v2.mjs`. Исходный код лежит в `server/` и `public/`.

## Что работает

### Участник
- **Главная (Rewards-first):** баланс, **«Моя цель»** с честным прогрессом и списком заданий, которые к ней приведут, витрина награды, полка наград, задания по интересам, недавняя активность.
- **Каталог наград:** фильтр по категориям, переключатель «Хватает баллов», сортировка, прогресс по каждой награде («ещё 10 AB»), реальный остаток, кнопка «В цель».
- **Страница награды:** изображение, описание, стоимость, остаток, прогресс, порядок получения в 3 шага, инструкция активации, ваши коды, задания «где заработать». Обмен подтверждается в диалоге, код показывается сразу.
- **Задания:** карточка показывает компанию, требования и строку обмена `≈ 15 мин ⇄ +50 AB`. На странице задания: шаги, способ проверки, какие данные получит компания, таймер, ответы (оценка, текст, выбор, **ссылка-доказательство**) и статус проверки по шагам.
- **Активность:** начисления, списания, отправленные и отклонённые ответы по дням, фильтры, сверка баланса с журналом.
- **Профиль и настройки:** интересы, Telegram, репутация, **отключение Telegram-уведомлений**, **выгрузка всех своих данных в JSON**, выход.

### Компания
- **Обзор:** свободный бюджет, резерв, подтверждённые результаты, очередь проверки, доля одобренных, цена результата; таблица кампаний с мини-воронкой.
- **Создание и редактирование кампании:** шаги, оценка времени, аудитория, вопросы, условия проверки, живой расчёт бюджета. При редактировании изменение числа мест само резервирует или возвращает бюджет. Награду после публикации менять нельзя. Вопросы блокируются после первого ответа.
- **Кампания:** воронка «начали → отправили → подтверждено / отклонено», качество, средняя оценка, среднее время, расходы; очередь проверки с флагами автопроверки и репутацией; отчёт с графиками; экспорт CSV; пауза и закрытие с возвратом остатка.
- **Награды:** создание с **загрузкой картинки** (PNG/JPEG/WebP, проверка сигнатуры), категории, инструкция активации, скрытие из каталога, пополнение запаса.
- **Бюджет:** журнал операций; пополнение без оплаты — только в демо-режиме.

### Telegram-бот
Привязка по коду (1 Telegram = 1 аккаунт), уведомления «🎉 +50 AB Points / Your task was approved / New balance», команды `/balance`, `/history`, `/tasks`, `/unlink`, публикация новых заданий в группу, `/chatid` для получения ID группы. Режимы polling и webhook.

## Безопасность и деньги

- Баланс меняет только сервер через `postTransaction()`: запись в журнал и обновление баланса выполняются атомарно. Баланс сверяется с суммой транзакций (`/api/health`, экран активности).
- **Идемпотентность:** финансовые операции (отправка ответа, одобрение, обмен на награду, пополнение, создание и изменение кампании) принимают заголовок `Idempotency-Key`. Повтор запроса возвращает сохранённый ответ и не списывает и не начисляет дважды. Клиент отправляет ключ автоматически.
- Бюджет кампании резервируется заранее. Награда за результат выплачивается только из резерва и только один раз.
- Пароли хранятся как scrypt-хэши; сессии в HttpOnly-cookie; защита от CSRF (только JSON и проверка Origin); ограничение попыток входа; строгий CSP.
- Картинки: только PNG/JPEG/WebP с проверкой сигнатуры, SVG запрещён, отдаются с `nosniff` и `sandbox`.
- **`DEMO_MODE=0`** отключает пополнение бюджета без оплаты и пометки демо.

## Честный дизайн

Нет бесконечной ленты, фальшивых таймеров, искусственного дефицита и скрытых условий. Остаток наград — реальный запас компании. AB Points — внутренние баллы платформы, не деньги и не криптовалюта. Демо-данные помечены как «демо». Обоснование: [`docs/RESEARCH.md`](docs/RESEARCH.md).

## Telegram (5 минут)

1. [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. Скопируйте `.env.example` в `.env` и укажите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_BOT_USERNAME` (без @).
3. Для группы: добавьте бота администратором, напишите в группе `/chatid` и укажите полученное число в `TELEGRAM_GROUP_ID`.
4. На сервере с HTTPS (Render и т.п.): `TELEGRAM_MODE=webhook`, `PUBLIC_URL=https://ваш-адрес` (без `/` в конце).

## Деплой (Render)

New → Web Service → репозиторий. Build: `npm install`, Start: `npm start`, Free. Переменные: `NODE_VERSION=22`, `PUBLIC_URL`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`, `TELEGRAM_MODE=webhook`, `TELEGRAM_WEBHOOK_SECRET`, при необходимости `TELEGRAM_GROUP_ID`. На бесплатном тарифе база сбрасывается при перезапуске; для постоянных данных нужна PostgreSQL ([`db/schema.postgres.sql`](db/schema.postgres.sql) — черновик схемы, рабочая база — SQLite).

## Обновление со старой версии

База версии 1 обновляется автоматически: при запуске добавляются новые колонки, данные и баланс сохраняются. `npm run seed` запускать **не нужно**.
